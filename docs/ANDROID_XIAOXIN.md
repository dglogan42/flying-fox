# Moved: generic China sideload APK

The Xiaoxin Pro–only channel was generalized into a **single China-market sideload APK**
for **all Chinese tablets and phones** (no Google Play).

→ See **[ANDROID_CHINA_SIDELOAD.md](ANDROID_CHINA_SIDELOAD.md)**

```bash
./Tools/build.sh android-china
# → Builds/Android-China/FlyingFox-China.apk
```

Legacy CLI aliases (`android-xiaoxin`, `xiaoxin-pro`) still build the same generic APK.

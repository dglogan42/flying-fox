# Flying Fox — Switch control card (for manual / eShop)

| Control | Action |
|---------|--------|
| Left stick / D-pad | Move cursor to a valid hex |
| A | Place tile |
| B / ZR | Rotate clockwise |
| Y / ZL | Rotate counter-clockwise |
| X | Cycle hand |
| L / R | Previous / next hand tile |
| Right stick | Pan map |
| + | Pause / confirm |
| − | Abandon run (with confirm) |

**Tip:** Match edges to score. Forest, Meadow, Water, and Rock each grant a fox ability. The den is neutral and connects to every biome.

# Flying Fox — Switch control card (for manual / eShop)

| Control | Action |
|---------|--------|
| Left stick / D-pad | Move cursor to a valid hex |
| A | Place tile |
| B / ZR | Rotate clockwise |
| Y | Rotate counter-clockwise |
| X | Cycle hand |
| L / R | Previous hand / rotate |
| Right stick | Pan map |
| **+** / **Esc** | **Pause / resume** |
| **−** | Open pause (use menu to abandon) |
| Pause → Resume | Return to game |
| Pause → New run | Start Classic again |
| Pause → Abandon… | Confirm end run |
| Dock / undock | UI scale + safe area update automatically |

**Tip:** Match edges to score. Forest, Meadow, Water, and Rock each grant a fox ability. The den is neutral and connects to every biome.

**TV (docked):** Larger UI, overscan margin. **Handheld:** denser UI, tighter camera.
